# Contract languages

Trocto (`.tc`) is the language for new native AstroLune contracts. The [Trocto documentation](trocto/README.md) collects the language overview, supported syntax, state capabilities, LLVM compilation, native isolation, examples and command-line workflow.

Historical WebAssembly ABI-v2 deployments retain their original semantics and Rust tooling. Their [sandbox and tooling reference](../contracts/29-parallel-payments-and-wasm.md#webassembly-abi-v2), [Rust SDK](../contracts/31-rust-sdk-and-wallet-vaults.md#allocation-free-rust-contracts) and [signed contract model](../contracts/30-signed-contracts.md) are documented in the contracts section.

For packaging, deployment, calls, resource accounting and compatibility, continue with [smart contracts](../contracts/README.md).
